# Kashnio Protocol v2 pre-audit engineering milestone — 2026-08-12

Kashnio has activated Protocol v2 on the public testnet and completed the project-controlled pre-audit engineering checklist. This milestone extends the protocol beyond the original public-testnet foundation while preserving explicit versioning, deterministic execution, state commitments, and fail-closed operational boundaries.

## Completed engineering scope

- Validator economics, delegation, unbonding, deterministic rewards, and validator-accountability mechanics
- Validator lifecycle and registry state
- Governance, treasury accounting, proposal voting, and controlled execution boundaries
- Fungible-token and non-fungible-asset transaction families
- Deterministic WASM deployment and invocation with bounded execution rules
- Versioned storage, migration, recovery, and unified state-commitment foundations
- Protocol-facing RPC, indexer, SDK, explorer, and wallet integration surfaces
- Cross-platform and multi-validator qualification paths for Protocol v2 behavior
- Signed RC7 deployment across all three testnet validators
- Live wallet, RPC, indexer, explorer, and KDGTEST asset verification
- Recovery, monitoring, backup, fault-injection, and security-preflight evidence

## Verified testnet state

All three validators run the RC7 Protocol v2 node and have repeatedly reported matching finalized checkpoints, state roots, and validator snapshots. The public wallet, RPC, indexer, and explorer were verified end to end against live Protocol v2 state.

This completes Kashnio's internal engineering checklist. It does not constitute an independent security audit, economic audit, production certification, or mainnet authorization.

## What comes next

The next work focuses on sustained public-testnet evidence, independent validator participation, external audit, and M7 interoperability. The planned M7 roadmap includes proof-verifier interfaces and a carefully bounded EVM-compatibility layer for familiar Ethereum application, wallet, and JSON-RPC workflows.

M7 and EVM compatibility are roadmap items, not live features. Their architecture, execution model, security boundaries, compatibility level, upgrade controls, and activation criteria remain subject to specification, testing, and independent review.
