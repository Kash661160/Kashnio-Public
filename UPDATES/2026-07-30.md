# Kashnio development update — 2026-07-30

> Historical record: this page describes the network as it existed on
> 2026-07-30. For the current Protocol v2 testnet and internal pre-audit status,
> see the [2026-08-12 update](2026-08-12.md).

Kashnio has progressed from its initial Layer-1 foundation into a broader public-testnet ecosystem. The project now combines a validator network, checkpoint finality, persistent state, public data services, a self-custody wallet, an explorer, operator tooling, signed releases, and gated candidates for later protocol expansion.

## Recent public progress

### Signed validator release

- Signed RC12 testnet validator packages are available for Linux x86_64 and ARM64 operators.
- The public release includes SHA-256 checksums, Sigstore verification bundles, release provenance, and operator verification instructions.
- Operators are expected to verify the selected package before installation.

[View the RC12 release](https://github.com/Kash661160/Kashnio-Public/releases/tag/testnet-v0.1.0-rc12)

### Public-testnet services

- The three-validator public-beta configuration continues to use certified checkpoints and matching state-root verification.
- RPC and finalized-state indexer boundaries have been strengthened with bounded access, incremental synchronization, pagination, and recovery qualification tooling.
- Explorer coverage includes transactions, accounts, checkpoints, validators, receipts, and network status.
- Monitoring, restart checks, backup procedures, and replacement-indexer comparison remain part of the active operating program.

### Wallet beta

- The self-custody wallet supports encrypted multi-account storage, local signing, backup and recovery, finalized transaction history, fee estimates, chain-bound address validation, auto-locking, and fail-closed network states.
- Mobile layouts and Progressive Web App behavior have been improved for the continuing beta program.
- Physical-device, hostile-browser, hardware-signing, and independent review gates remain before production representation.

### Protocol expansion candidates

Development candidates now cover validator economics, delegation and unbonding, deterministic reward accounting, governance, fungible and non-fungible assets, and deterministic WASM contract execution.

These capabilities are **not active on the public testnet**. They remain behind explicit protocol-version, migration, multi-validator, economic, legal, and independent security-review gates. Protocol v1 remains authoritative.

### Audit and launch discipline

Kashnio has prepared audit-readiness material and additional qualification workflows. Audit readiness is not an audit completion claim. Mainnet has not launched and will require independent review, remediation confirmation, long-duration network evidence, independent validator participation, frozen production parameters, a reproducible genesis ceremony, and explicit launch authorization.

## Current status

- **Stage:** Public testnet beta
- **Network:** `dag-l1-testnet-2`
- **Active protocol:** Version 1
- **Latest signed operator release:** RC12
- **Validator configuration:** Three active validator identities
- **Mainnet:** Not launched

KDG on the testnet has no monetary value. Public-testnet services may be changed, restarted, or temporarily unavailable as qualification continues.
