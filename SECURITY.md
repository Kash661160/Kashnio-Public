# Kashnio security reporting

Please report suspected security vulnerabilities privately to
`support@kashnio.com`.

Include:

- the affected Kashnio service or component;
- a concise description of the issue and potential impact;
- reproducible steps or a minimal proof of concept;
- relevant transaction IDs, checkpoint identifiers, or timestamps; and
- a safe method for follow-up communication.

Do not publish an uncoordinated exploit, attempt to access other users' data,
disrupt validators or public services, extract secrets, or test against
mainnet-value systems.

The presence of this reporting channel does not create a bug-bounty promise,
safe-harbor agreement, employment relationship, or payment obligation.
Kashnio will acknowledge credible reports and coordinate disclosure when
appropriate.

For ordinary support questions, use https://kashnio.com/support.
